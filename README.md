# Road-Accident-Dashboard

## Project objective
Developed an interactive Tableau Road Accident Dashboard to analyze accident severity, casualties, vehicle types, road conditions, weather, and accident hotspots. Created KPIs, interactive filters, charts, and maps to identify trends and provide data-driven road safety insights.

## Questions / KPIs
-  What is the total number of accidents?
-  What is the total number of casualties?
-  How many casualties are Fatal, Serious, and Slight?
-  How has the accident rate changed compared with the previous year?
-  Which vehicle type has the highest serious casualties?
-  Which weather and road-surface conditions have the most accidents?
-  Which road type has the highest serious casualties?
-  Where are the major accident hotspots?
